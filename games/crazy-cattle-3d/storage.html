A Godot engine only asks for a sync when it closes or renames a file, so flushes is the count of times it has actually saved — on a clean install it stays at 0 until the game writes something of its own. browser store keys is the frame's own localStorage, which should hold this document and nothing belonging to the game.
Raw document
This game's save is a plain-text Godot resource, user://crazysavefile.tres, so every field below is readable and editable as it stands. Edit the document and press Import into game to store it: the frame reloads because the engine reads its save once, while booting. A running engine is also a writer, so it will overwrite the document on its next save — import while the game is sitting on a menu, not mid-round.
