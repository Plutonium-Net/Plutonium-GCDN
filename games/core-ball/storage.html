level loaded is the frame's own GlobalLevel, which it read out of the save while booting — the honest answer to "did the game get the new value". begin screen says is the label on the start panel, drawn from that same number.
Raw document
Editing the document and pressing Import into game stores it and reloads the frame, because the game reads the level once, at boot. The game itself writes on only two occasions: when a level is passed (it stores the next level) and when RESET is pressed (it stores 1). So an empty document right after a fresh boot is the expected state, not a dead patch.
